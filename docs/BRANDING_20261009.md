# 生图素材与接入说明

本轮按用户最后提供的二次元头像参考重新设计图标；此前玻璃课表图标不用于交付。最终图像使用 Codex 内置 imagegen 生成，没有调用 CLI 或要求额外 API Key。用户参考图片仅指导风格，不作为正式素材提交。

## 正式文件

- `app/src/main/res/drawable-nodpi/campus_icon_portrait.png`：本应用扁平二次元头像，课间为深蓝发与单金色发夹，知学为冰蓝发与双蓝色发夹。
- 同目录 `campus_companion_idle.png`、`campus_companion_peek.png`、`campus_companion_rest.png`、`campus_companion_thinking.png`、`campus_companion_greeting.png`：校园助手小澄的五张透明状态图。
- `drawable/campus_icon_foreground.xml`、`campus_icon_background.xml`、`campus_icon_monochrome.xml`：Adaptive Icon、暗色背景与主题单色头像。保留各应用原有 launcher 组件及图标别名；原签名不变。
- `cn/scvtc/campus/CampusCompanion.kt`：离开页面/后台停止待机循环；按屏幕尺寸在 IO 线程解码，缓存上限 2 MiB；尊重减少动画；显隐、大小与拖动位置延用原偏好键。

图标与角色是原创生成插画，不属于学校官方标志。角色负责界面表现，不表示新增任何学校接口或云端 AI 服务。
