# 使用方法

## 安装与首次登录

安装本项目发布的 APK。已有川职·课间时直接覆盖安装，保留原数据；请勿先卸载或清除应用数据。新 APK 的包名、签名和版本码必须满足覆盖升级条件。

在课程菜单选择“教务系统导入”，或到设置中的“自动刷新课表”，点击“连接川职教务”。完成官方 CAS 页面登录，学校要求的验证按提示操作。App 会继续建立教务 Session，调用学生身份和课表 API；只有身份与课表都成功后才提示完成。

首次完成后，App 保存本机加密凭据和课表。再次启动时优先使用现有会话；过期后自动尝试恢复并继续读取，不要求每次重新输入。学校改密码、要求补充认证或网络不可用时，会保留课表并说明本次同步没有完成。

## 查看与编辑

首页保留 SleepDown 的日、周视图、切周、课程详情、编辑和玻璃动效。底部为课程与设置两个入口。可自定义壁纸、颜色、透明度、作息和小组件。

学校接口没有提供的钟点不会填入假作息。需要准确提醒时，先在当前课表的作息设置填写实际上下课时间，再开启通知权限。

设置“自动刷新课表”中可选择每天、每七天或关闭自动刷新，也可点“立即刷新课表”。自动同步保留手动添加、修改和删除，不用每次导入覆盖本地编辑。

## 自己调节效果

默认保留原版玻璃和动效，机型不会自动降低效果。设置 → 通用设置 → 液态玻璃，可预览并调整首页玻璃模糊；当前课表设置中的课程卡片参数独立保存。参数修改由你决定，调整不会改变课表或登录记录。

## 成绩、刷新与校园助手

设置中的“成绩与学分”直接读取学校 JSON：成绩支持实际学期列表，学分分别显示官方毕业要求和成绩所得。重修按课程代码合并；暂无成绩时显示尚未读取，不填写假零值或 GPA。

首页右上角液态玻璃刷新按钮沿用已连接账号；同步中不可重复触发。状态显示正在认证、读取或保存，只有数据成功入库才更新成功时间。

小澄有微笑、侧目和眨眼待机；同步时思考，轻点后回应。设置可隐藏、调整大小，标题区域可拖动保存位置。切到后台或系统关闭动画时停止待机循环。

## 登录与网络问题

“同步未完成”表示本次没有拿到完整、已验证的新数据；已有课程仍可查看。请先确认官网能访问以及校园网络状态，再重新同步。学校要求验证时使用“重新登录”，无须清库。

“退出登录”取消自动同步并移除本机保存的学校认证，离线课表继续保留。卸载和清应用数据会丢失本机密钥；把加密文件复制到另一台手机不能恢复密码。

两版云服务目前暂停。主动导出的课表和备份由你选择存放位置，请作为个人文件保管，不上传包含个人信息的故障报告。
