# 1.2.3 修改记录

这一版处理连接川职教务与首次使用流程。沿用包名、签名、Room 数据库和原生 Miuix 底栏，没有更换课表基底。

| 问题 | 修改文件 | 结果与验证范围 |
| --- | --- | --- |
| 登录被提示需要补充认证 | `official-login-memory.js`、`CasAuthManager.kt`、`JwxtApi.kt` | 只有可见的验证控件才算验证码；普通 iView 弹窗不再直接触发补充认证。表单未就绪和回调超时分别提示。实际学校登录由用户验收 |
| 首次核验后账号连接未及时保存 | `ScvtcNativeBridge.kt`、`OfficialLoginMemory.kt`、`AcademicRepository.kt` | 主动登录结束旧会话读取，身份与校历核验后先保存账号课表连接、安排后台刷新，再读取课程；不删除已有编辑 |
| 新装空应用没有明确登录入口 | `MainActivity.kt` | 先完成本地记录读取与旧库迁移，再判断是否引导；已有记录或账号直接进入应用 |
| 「连接川职教务」按钮布局 | `AutoRefreshScheduleUi.kt`、`ScvtcLoginActivity.kt`、Manifest | 按钮使用完整行宽和留白；登录页限制大屏宽度，处理键盘、导航栏与输入法提交 |
| 日夜切换突变 | `MainActivity.kt`、`AnimatedThemePalette.kt` | 保留原配色与玻璃参数，统一过渡主题颜色；尊重系统关闭动画的设置 |
| 项目介绍不够清楚 | README、使用说明、构建说明 | 说明两版区别、首次连接、原生数据流程和自行构建，发布说明使用面向用户的文字 |

截图对应：本轮 IMG-01 至 IMG-05 主要来自知学；课间相同的教务登录入口与按钮布局在本版一并修正。此前成绩、学分、图标、角色、壁纸、更新与隐私功能保留。

编译、正式打包、原签名与源码核对结果见根目录 `VERIFICATION.md`。本轮不连接手机，不运行功能或性能测试。旧版实际登录、会话自然过期恢复、键盘布局和覆盖升级后的体验仍需实机验收。
