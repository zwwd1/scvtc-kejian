# 隐私与加密

川职·课间由 zwwd1 维护，是基于 SleepDown 的独立非官方分支。学校认证与数据请求直接访问学校服务。

| 数据 | 保护方式 | 导出与分享 |
| --- | --- | --- |
| 学校密码、表单绑定、Session 备份 | Android Keystore 管理 AES-256-GCM 密钥，账号作为关联数据 | 不进入普通课表备份、Git 或明文诊断 |
| 自动同步连接配置 | 本机 Keystore 与 AES-GCM | 不通过系统备份带到其他设备 |
| 成绩、学期查询、毕业要求 | 账号/学期关联的 AES-GCM，密文写入原 Room 缓存表 | 不随普通课程备份迁移登录材料 |
| 学期、课程和作息 | 应用私有 Room 数据库、Android 沙箱与设备存储加密 | 只在主动导出时分享 |
| APK 签名私钥 | 开发者仓库外的私有配置 | 不随源码和 APK 分发 |

普通 Room 数据库没有使用 SQLCipher，不称为全库应用级加密。Keystore 密钥保护凭据；Android 沙箱和设备加密保护普通缓存，两者的保护范围不同。

系统自动云备份和设备迁移备份关闭。本版本暂停云同步、上游云配置和安装统计。用户主动使用的 AI、天气、插件和更新服务仍可能联网，按对应服务说明处理所选数据。密码不会发送给 AI 服务或项目维护者。

认证只接受明确的学校 HTTPS 来源。暂存密码在验证学生身份后才正式保存，过期候选清除；重新认证有超时，不无限尝试。网络、认证或解析失败不清除最后成功的课表。

退出教务连接移除相应密码、认证备份和 App WebView 登录状态，保留课表。卸载或清应用数据会丢失密钥，旧加密文件不能跨设备恢复，需要重新登录。

公开仓库与反馈只保留必要的脱敏信息。账号、密码、Cookie、Token、真实抓包和私人 APK 签名配置不发布。导出的课表可能含课程、教师和地点，请自行保管。

生成角色与图标为公开项目素材；用户参考照片、支付原图、带真实数据的设备截图和新 APK 留在本机交付，不上传公开仓库。素材来源与处理方式见 [BRANDING_20261009.md](BRANDING_20261009.md)。
